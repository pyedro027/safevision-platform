# Proveniência da importação

A referência é a distribuição de 20/11/2026, na pasta do projeto V03 em `SAFEVISION_V03_ETAPA7_3_QUALIDADE_NAVEGACAO_QUEST2/02_CODIGO_VERSAO_C/dist`. O manifesto da ETAPA7.3 foi usado para conferir a fonte, a cópia de segurança independente e o conteúdo importado. O Blender e os demais artefatos de autoria ficam no acervo local. O modelo web é o GLB já exportado, conservado nos sete segmentos existentes.

Consulte [o inventário](INVENTARIO_VERSAO_C.md), [a auditoria](RELATORIO_AUDITORIA.md) e [os testes](RELATORIO_TESTES.md). Para continuidade consulte [o ponto de retomada](CONTINUIDADE_IA.md).

Para futuras importações, registrar o inventário e os hashes antes de copiar a distribuição. Validar navegação, colisões, estados técnicos e XR em ambiente separado.
