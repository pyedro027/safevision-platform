# Decisões da fundação

1. A branch de integração preserva os dois históricos através de um commit de merge. Os conflitos ocorreram somente em README, regras de exclusão e três documentos. A auditoria da versão importada substitui as afirmações antigas de que o pacote estava ausente. As recomendações compatíveis do PR #1 foram incorporadas aos documentos atuais.
2. Os 42 arquivos de `apps/viewer` preservam o conteúdo do manifesto C. O pacote continua em Babylon.js e JavaScript estático. Os sete segmentos continuam no mesmo caminho relativo.
3. A prévia estática deve sair de um commit conhecido em ambiente Vercel Preview. A implantação pública anterior da C permanece como referência de comportamento.
4. A plataforma de gerenciamento ficará em módulo separado. O visualizador legado continua responsável pela cena, interações e sessões XR. A autorização de projetos privados será aplicada no banco, com o proprietário derivado do usuário autenticado.
