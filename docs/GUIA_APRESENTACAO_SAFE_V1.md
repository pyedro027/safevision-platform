# Guia do apresentador

Abra a [apresentação local](http://127.0.0.1:4181/#apresentacao). Verifique a saída de vídeo, o tamanho das letras e a entrada no modelo antes de receber o público. Use visitante quando a apresentação dispensar dados privados.

## Preparar a máquina

Na pasta do repositório, inicie a distribuição pronta com `python scripts/servir-demonstracao.py`. Mantenha o terminal aberto. Com o servidor ativo, entre em `http://127.0.0.1:4181/`. Se a porta já estiver ocupada, confira o endereço antes de iniciar outra instância. Para gerar a distribuição em uma instalação nova, consulte o procedimento de build e configuração pública no [QA](QA_MISSAO_16.md).

Use **Conta → Entrar** para mostrar o perfil do titular, depois **Meus projetos** e o histórico de um projeto autorizado. Para uma demonstração pública sem carteira, comece como visitante. No Studio, o par oficial é SAFEVISION_V03_PLANTAS_2D.pdf e SAFEVISION_V03_DETALHE_TECNICO_R03.pdf.

Dentro do tour, mova-se com WASD e olhe com o mouse. Use Tab para liberar o cursor e Esc para pausar. **Controles na tela** oferece navegação alternativa. **Ambientes** muda o ponto de visita. Em **Riscos**, escolha o caso, compare os dois estados e use **Avaliar este caso** para abrir sua ficha. O botão de retorno informa para onde você vai.

## Roteiro curto · aproximadamente três minutos

“Esta é a Clínica ÁUREA. Na SAFEVISION, o profissional percorre o projeto antes da obra. Vamos observar o encontro entre a tubulação e a viga.” Abra **Casos → R05**. Alterne **Com problema** e **Proposta** e mantenha o ponto de vista. “Este encontro já está documentado. A decisão sobre a solução depende dos projetistas.” Abra **Avaliar este caso**, registre uma observação demonstrativa e mostre onde ela aparece no relatório. Encerre no roteiro.

## Roteiro estendido · aproximadamente dez minutos

1. Mostre a visão geral. Se o titular autorizar a exibição dos dados, abra um projeto de demonstração e seu histórico.
2. Abra a clínica e apresente a arquitetura. No Studio, escolha os dois PDFs oficiais ou o acesso demonstrativo. Explique que o Studio reconhece esses documentos e carrega a modelagem existente.
3. Mostre a recepção, abra Ambientes e visite um setor. Apresente R01 para circulação, R03 para transferência e R05 para compatibilização. Reserve R02 e R04 para perguntas. Alterne os estados de um caso sem deslocar a câmera.
4. Registre observação, situação e recomendação em uma ficha. Diferencie o texto do avaliador do conteúdo técnico preexistente. Abra o relatório e a impressão A4.
5. Retome o roteiro. Ao concluir, apresente a análise de projetos externos e a colaboração como possibilidades de evolução.

## Contingências

Com 3D lento, selecione **Desempenho** na pausa. Com falha de carregamento, tente novamente uma vez e use as imagens reais e fichas em **Clínica ÁUREA** para continuar. Se a autenticação estiver indisponível, use a demonstração visitante. Guarde o PDF de exemplo para uma apresentação sem navegador ou projetor 3D. A validação física de VR exige o headset.
